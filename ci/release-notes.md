<h1 align="center">The Simpsons: Road Rage for Android {{VERSION}}</h1>

<p align="center">
  An unofficial native Android port of the original Xbox version of <b>The Simpsons: Road Rage</b>,<br>
  statically recompiled to arm64 with Vulkan rendering, SDL3, and touch/controller support.
</p>

> [!NOTE]
> This release contains **no game assets**. You need the files from your own legally acquired copy of *The Simpsons: Road Rage* (Xbox, USA release, `default.xbe` SHA-1 `fd450329f44853575adf56baa13e79d938a9a7ca`).

## Installation
1. Download and install `{{APK}}` ({{SIZE}}).
2. Open **Road Rage** and allow **all files access** when it asks.
3. Copy the game into **`/storage/emulated/0/RoadRage`**, or into a `RoadRage` folder on your SD card: the disc image (`.iso`), or `default.xbe` with the rest of the disc's files and folders.

> If you don't grant all files access, put the game in `Android/data/com.roadrage.android/files/assets` instead. Settings, saves, logs and the shader cache are stored in `Android/data/com.roadrage.android/files`.
